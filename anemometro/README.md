# Anemómetro Ocupacional · MAV–PRO 600 SIM

Simulador didáctico de La Movida de SST Plus para practicar medición de velocidad del aire en ambientes ocupacionales y sistemas de ventilación.

## Modos

- HOT WIRE: bajas velocidades / ambiente ocupacional.
- VANE: corrientes definidas / rejillas y salidas de ventilación.
- PITOT: exploración avanzada de ductos mediante presión diferencial.

## Base documental

- ISO 7726:1998 / EN ISO 7726:2001 — instrumentos y métodos para magnitudes físicas del ambiente térmico.
- Manual Testo 425 — anemómetro térmico de hilo caliente.
- Manual Testo 410-1 — anemómetro de hélice.
- ISO 3966:2008 — método velocidad-área con tubos Pitot estáticos. Se usa como base didáctica del modo avanzado; la edición 2008 no es la edición vigente.

Incluye acceso de integrantes, promedio temporal y multipunto, SD, intensidad de turbulencia TU, perfil vertical cabeza/abdomen/tobillos, caudal Q=v×A, memoria local y prácticas guiadas.

> Recurso educativo. No sustituye un instrumento calibrado, la aplicación completa de las normas, la evaluación de incertidumbre ni un estudio profesional.
